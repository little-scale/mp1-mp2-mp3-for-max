mp3encode~ dynamically links LAME 3.100, built from the bundled upstream
source. source/vendor/lame-frame-bitrate.patch adds a between-frame bitrate
setter for the reservoir-disabled encoder. source/build-lame-macos.sh builds
the replaceable universal dylib. source/build-macos.sh embeds and signs it.
The original archive and the modified API header are in source/vendor.
See LAME-LGPL.txt for the LGPL license.

minimp3 by lieff and contributors is distributed under CC0. The original
dedication and warranty notice are included in source/vendor/minimp3.h.
The local 8 kHz mixed-block table uses six long scalefactor bands followed
by the final ten short-window groups. Its first Huffman region spans 72 lines and its
synthesis uses two long subbands.
Project: https://github.com/lieff/minimp3
Included header SHA-256:

The packer uses the Huffman code and length tables from LAME 3.100
libmp3lame/tables.c. source/vendor/pack_huffman.h retains their license
notice. The full upstream source, local source and build script are included.
source/vendor/pack_layout.h contains band widths and partitions from minimp3.
